## Key Decisions

- Rails 8.1.3 + Ruby 4.0.2 + Tailwind CSS v4 + SQLite3 — uses installed versions, not `--main`
- Tailwind v4 — utility classes mostly same as v3, no `tailwind.config.js` needed
- Auth: Rails 8 built-in auth generator (`has_secure_password`) + custom registration controller
- `Current.user == @topic.user` fails in views — use `authenticated?` helper first to ensure `resume_session` called, then compare with `.id`
- `PostsController` needs explicit `index`/`show` redirect actions for `allow_unauthenticated_access only: %i[ index show ]` to work (Rails 8.1 behavior)
- Topic `set_slug` callback: skip if slug already present (`return if slug.present?`), exclude current record from duplicate check
- SimpleCov: removed `minimum_coverage 80` constraint (fails when system tests run separately)

## Failed Approaches

- System tests: `@topic.user == Current.user` comparison fails in views because `Current.user` might not be hydrated before the comparison runs. Use `authenticated? && @topic.user_id == Current.user.id` instead.
- `.mb-6` CSS class selector ambiguous in system tests — added `#topic-header` ID for scoping.
- Topic `set_slug` callback was overwriting fixture slugs — added `return if slug.present?` guard and `where.not(id: id)` for self-exclusion.
