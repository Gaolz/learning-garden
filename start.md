# Start Here: My System for Active Learning

> "If you want to learn something, teach it. If you want to master something, build it."

---

## 🎯 The Four Pillars

### 1. Output-Driven Learning (English & Tech)
*   **The Rule:** No passive consumption without creation. 
*   **Action:** Write articles, "Today I Learned" (TIL) posts, or explanations as if teaching a beginner.
*   **Language Focus:** Write tech notes and documentation in English to bridge the gap between language and technology.

### 2. Project-Based Programming + AI Collaboration
*   **The Rule:** Build projects to break things; use AI to understand *why* they broke.
*   **AI Protocol (with Gao/Claude):** 
    *   Treat AI as a senior developer/tutor, not a code generator.
    *   Ask for high-quality materials, roadmaps, and deep-research insights.
    *   Answer the key foundational questions posed by AI to test true comprehension.
    *   *Avoid the copy-paste trap.* Understand every line of code.

### 3. Physical Strength (Body)
*   **The Rule:** Physical energy fuels mental clarity.
*   **Action:** Regular exercise to reset the brain, boost focus, and break through coding roadblocks.

### 4. Meditation & Alignment (Mind)
*   **The Rule:** Filter out the noise to remember the "Why."
*   **Action:** Daily/regular meditation to stay grounded, reduce cognitive overload, and maintain focus on what truly matters.
