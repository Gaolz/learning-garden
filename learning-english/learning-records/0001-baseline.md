# Baseline: CET-4 Level, Technical Communication Focus

User stated current level is CET-4 (College English Test Band 4, China). Implications:

- **Reading**: Can handle intermediate-level English text with moderate speed. Technical documentation reading is possible but likely involves mental translation — not yet direct comprehension.
- **Writing**: Can produce basic sentences with correct grammar for simple structures. Struggles with natural phrasing, idiomatic expressions, and the conventions of specific formats (blog posts, technical docs).
- **Speaking**: Can handle greetings and simple topics. Breaks down on unscripted, extended conversation — especially technical topics where vocabulary gaps compound fluency issues.
- **Listening**: Can understand clear, moderate-speed English. Native-speed conversation with connected speech and reductions is challenging.

## Key gap to close

The user can *understand* English but cannot yet *produce* it fluidly. The zone of proximal development is the transition from passive comprehension to active production — first in writing (lower pressure, editable), then in speaking (real-time, irreversible).

## Evidence

- CET-4 certification
- User's own description of goals: wants to write blog posts and talk with native speakers — implying these are not yet comfortable

## Implications for teaching

- Start with writing before speaking (editable, lower cognitive load)
- Use real tech contexts exclusively (documentation snippets, code review comments, blog post drafts)
- Focus on production from lesson 1 — every session must produce something original
- Address mental translation habit: design exercises that force direct English thinking
- Grammar: teach only the patterns that differ from Chinese and cause errors in production (articles, tenses, prepositions)
