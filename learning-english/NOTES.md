# Teacher's Notes

## User Preferences
- Focus on practical usage, not grammar theory
- Prefer tech/dev contexts for examples
- Learning through active production (speaking, writing) over passive consumption

## Working Notes
- User is at CET-4 level: basic conversation OK, struggles with production
- Zone of proximal development: move from "can understand" to "can produce"
- Key gap: mental translation habit → direct English thinking

## Lesson Design Principles
- Every lesson produces something (a sentence, a paragraph, a spoken answer)
- Immediate feedback loop essential
- Keep grammar explanations minimal — only what's needed for the task
- Use real tech contexts (documentation, code review, standup, blog posts)
