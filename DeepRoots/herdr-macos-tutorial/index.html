Keep coding agents running — without keeping them in view.

Herdr is a persistent terminal workspace manager for Codex, Claude Code, and other coding agents. It owns their panes, keeps work alive after you detach, and shows which agent needs attention.

Best mental model
tmux-style persistence + project workspaces + agent-aware status

Understand the hierarchy

Four concepts are enough to begin.

Start with one workspace per project or repository. A pane is a real terminal; an agent is a recognized process inside one.

Workspace

A project container. Use one repo, project, or investigation per workspace.

Tab

A view inside the project: Agent, Dev, Review, logs, or tests.

Pane

A real terminal for a shell, Codex, Claude, a server, or logs.

Agent

A process Herdr can track as working, blocked, done, or idle.

First run

Open a project, then run Herdr and your normal agent.

Open TerminalTerminal, iTerm2, Ghostty, or your preferred terminal.
Enter a projectChoose the directory you actually want to work in.
Launch HerdrIt creates the first workspace when needed.
Start your agentUse your normal Codex, Claude, or OpenCode command.
Read the sidebarConfirm Herdr recognizes the agent and its state.
cd ~/Projects/my-project
herdr

# inside the first pane
codex
# or
claude

Success checkYou are looking at a Herdr workspace with a real terminal pane containing Codex or Claude, and the agent appears in the sidebar.

Daily workflow

Use the mouse first; add only a few keys later.

Mouse-first layout

  • Click a pane, tab, workspace, or agent to focus it.
  • Right-click for context menus, new tabs, and pane splits.
  • Drag split borders to resize panes.
  • Drag-select terminal text to copy; double-click a token to copy it.

Programming + Codex setup

  • Tab 1 — Agent: Codex
  • Tab 2 — Dev: local server, build, or tests
  • Tab 3 — Review: git status, diffs, manual checks
  • Optional split: Codex left, shell or logs right.
  • Let the sidebar replace repeated terminal polling.

Keyboard essentials

Every shortcut starts with Ctrl+B.

Press the prefix, release it, then press the action key. Example: Ctrl+B, then C creates a tab.

Leave safely

Detach is not stop.

What you doWhat happensUse when
Ctrl+B, then QClient detaches; server and pane processes keep running.You want to leave Herdr but keep Codex or tests alive.
Close the terminal windowNormally equivalent to leaving the client; background server continues.You are done watching for now.
Run herdr againReattaches to the default background session.You want to continue later.
herdr server stopStops server and pane processes.You intentionally want to end everything in the session.

After a machine or server restartHerdr restores workspace, tab, pane layout, cwd, and focus, but ordinary processes do not survive. Supported agents can resume conversations with a valid integration or session reference; current docs support Codex native restore.

Agent dashboard

Use the sidebar to decide what deserves attention.

The productivity gain is simple: stop polling every agent terminal.

workingThe agent is actively running.
blockedIt needs input, approval, or a decision.
doneFinished; you have not viewed completion yet.
idleFinished or waiting; ready for input.
unknownHerdr cannot classify it confidently.

Integration and commands

Check integration before guessing.

Agent integration

Herdr detects Codex out of the box. Integrations improve session identity and restore behavior.

herdr integration status
herdr integration install <agent>

For Codex, use the identifier shown by Herdr’s own help; do not guess if your installed CLI reports a different name.

Command cheat sheet

  • herdr — launch or attach
  • herdr status — session, server, and client status
  • herdr -V — installed version
  • herdr session list — named sessions
  • herdr --default-config — default config
  • herdr completion zsh — zsh completion

Configure and copy

Customize only after the default feels natural.

Optional configuration

Default prefix: Ctrl+B. For example, change it to Ctrl+A.

[keys]
prefix = "ctrl+a"

[ui]
mouse_capture = false

On macOS, Ctrl+Alt combinations are generally safer than Option/Alt because the OS or terminal may intercept keys.

Copy terminal history

  1. Ctrl+B, then [ enters copy mode.
  2. Move with H/J/K/L or PageUp/PageDown.
  3. Use / forward or ? backward.
  4. V or Space selects; Y or Enter copies.
  5. Q or Esc exits.

Troubleshooting

Start with status, then isolate the failure.

herdr -V
herdr status
herdr is not found

Restart Terminal so PATH reloads, then confirm the install location is on PATH.

A direct shortcut does nothing

macOS or the outer terminal may have consumed it before Herdr received it.

Keychain-backed tools fail inside Herdr

Run launchctl managername. If it prints Background, stop the server and restart from a normal GUI terminal. Stopping the server exits panes.

Where are the logs?

~/.config/herdr/herdr.log, herdr-client.log, and herdr-server.log.

Practice and habits

Learn one small loop before scaling up.

10-minute practice

  • Open a real project and run herdr.
  • Start codex in the first pane.
  • Split right; run git status or your test command.
  • Move with H/J/K/L, create a second tab with C, open navigation with W.
  • Detach with Q; close and reopen the outer terminal; run herdr again.
  • Confirm the same live session remains.

Minimal first-week setup

  • Use only the default session.
  • One workspace per active programming project.
  • At most 2–3 tabs: Agent / Dev / Review.
  • One primary Codex agent until the sidebar feels natural.
  • Use mouse for layout; memorize C, V, -, HJKL, W, Q.
  • Detach instead of killing the session.

Avoid these mistakes

Keep the structure small until it becomes automatic.

Named sessions per project

Start with workspaces. Named sessions are for separate runtime namespaces.

Stopping to leave

Detach instead; herdr server stop ends pane processes.

Too many agents

Learn with one Codex pane and one shell or test pane.

Manual polling

The status sidebar eliminates it. Configure less on day one.
