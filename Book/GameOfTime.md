# 《时间游戏》阅读框架

## 第一层：概念底层
**核心问题：周洛华所说的“时间”，与钟表时间、物理时间有何本质不同？**

| 小节 | 子问题（辅助理解） |
|------|-------------------|
| 时间到底是什么 | 时间是客观存在的，还是被人类发明出来的“博弈工具”？ |
| 时间的维度 / 构成 / 形式 | 时间是连续的还是分段的？它是否等价于“人的注意力”？ |
| 时间的创造 / 买卖 | 如果时间可以被“创造”，那创造它的动力是什么？谁在买，谁在卖？ |

---

## 第二层：游戏机制
**核心问题：“时间游戏”是如何被发起、维持、切换和终结的？**

| 小节 | 子问题（辅助理解） |
|------|-------------------|
| 集体游戏 / 共同风险 | 人类为什么要“一起玩”时间游戏？是为了对抗什么样的共同风险？ |
| 游戏的发起 / 切换 / 维持 / 结束 | 一个游戏在什么条件下会“切换”？是外部冲击，还是内部估值体系崩了？ |
| “人上人”模式（成因 / 机制 / 应对） | 这种模式的本质是“等级固化”吗？个体如何应对？ |
| “天外天”模式（成因 / 机制 / 应对） | 这种模式是否更接近“自由人的联合”？它依赖什么条件才能成立？ |

---

## 第三层：现实投影
**核心问题：周洛华的“时间游戏”框架，如何解释我们今天面对的现实问题？**

| 小节 | 子问题（辅助理解） |
|------|-------------------|
| 个体玩家与游戏组织者 | 谁是“游戏组织者”？他们的既得利益是什么？ |
| 定价与报价 / 利率 / 通胀 / 债务 / 货币政策 | 这些金融现象，如何被翻译成“时间游戏”的语言？ |
| 房产游戏 / 股票游戏 | 这两种游戏，哪一种更接近“篮子”，哪一种更接近“圈子”？ |
| 捷径与大道 / 规则与产权 | “捷径”是游戏漏洞，还是另一种合法策略？ |
| 老龄化 / 内需 / 电力与算力 | 这三个问题，在“时间游戏”框架下是同一个问题吗？ |
| 面子 / 孝子 / 种子 | 三个“子”分别对应哪三种时间策略？ |
